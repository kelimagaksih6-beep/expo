# Бесплатный ИИ-тренер: подключение LIME FIT 0.6

Интерфейс чата и серверная часть подготовлены. Пока ключ Groq не добавлен в Netlify и Functions не развёрнуты, приложение честно показывает «ИИ не подключён». Реальные ответы Groq в среде разработки не проверены: ключа здесь нет.

## 1. Сохранить данные

В текущем приложении экспортируй резервную копию JSON. Обновляй **существующий сайт Netlify**, сохраняя его адрес: данные хранятся в браузере для конкретного адреса. Новый адрес не получит старую историю автоматически — потребуется импорт копии.

## 2. Получить ключ Groq

Открой https://console.groq.com/keys и создай ключ. На странице Groq ключу не нужно давать имя для приложения: после создания сохрани показанное значение. По умолчанию приложение использует модель `llama-3.3-70b-versatile`; другую доступную модель можно задать через `LIME_GROQ_MODEL`.

Не подключай платный тариф. Бесплатность зависит от актуальных условий Groq, региона и квот; безлимитной работы нет. Не присылай ключ в чат и не вставляй его в файлы приложения.

В приложении передача программы и результатов требует согласия. Имя, заметки и ограничения из профиля автоматически не отправляются. Не вводи в чат личные или медицинские сведения. Передаются вопрос, последние сообщения, сокращённая программа и до трёх завершённых тренировок; это не вся история. Обработка данных подчиняется актуальным условиям Groq.

## 3. Подключить GitHub к существующему сайту Netlify

Простая загрузка ZIP через Netlify Drop **не устанавливает серверные функции**. Нужна сборка из Git.

В панели существующего сайта найди настройки Build & deploy → Continuous deployment → Repository и подключи GitHub:

- Репозиторий: `kelimagaksih6-beep/expo`.
- Ветка: `lime-fit-web-preview-20261015` (не `main`).
- Base directory: оставить пустым.
- Build command: `npm run build`.
- Publish directory: `dist`.
- Functions directory: `netlify/functions` (уже задан в `netlify.toml`).

Названия пунктов панели могут отличаться. Если сайт ещё не создан, импортируй этот репозиторий как новый проект на бесплатном плане Netlify, затем восстанови резервную копию. Не подключай платный план или автоматическую покупку дополнительных квот. Бесплатный хостинг тоже имеет лимиты и может приостановить сайт при их исчерпании.

## 4. Добавить серверные переменные

В Netlify → Environment variables добавь значения для Production с областью **Functions**, если выбор области доступен:

| Имя | Значение |
| --- | --- |
| `GROQ_API_KEY` | Сохранённый ключ из Groq Console |
| `LIME_COACH_PASSWORD` | Отдельный пароль для входа в тренера, 16–256 символов |
| `LIME_SESSION_SECRET` | Случайная строка не короче 32 символов, сгенерированная менеджером паролей |
| `LIME_GROQ_MODEL` | Необязательно: имя доступной модели; по умолчанию `llama-3.3-70b-versatile` |

Не добавляй префиксы `EXPO_PUBLIC_`, `VITE_` или `NEXT_PUBLIC_`. Значения должны оставаться на сервере. Пароль тренера и секрет сессии — разные значения. Ключ API не используется как пароль входа. Нажми Deploy / Trigger deploy после сохранения переменных.

## 5. Проверить на iPhone

После успешного deploy проверь в панели Functions наличие `coach-auth` и `coach-chat`. Открой прежний HTTPS-адрес в Safari → «Тренер». Введи **пароль тренера**, разреши передачу программы и результатов, отправь короткий вопрос. Первый настоящий ответ подтвердит соединение с моделью. Чат не изменяет программу автоматически. Сеанс входа действует час, переписка хранится только в памяти открытого экрана.

Если «ИИ не подключён» — проверь переменные, Functions и повтори deploy. Если модель недоступна — проверь ключ, имя модели, регион и бесплатный тариф Groq. При исчерпании квоты дождись её восстановления; приложение не переключается автоматически на платную модель. Частые запросы также ограничиваются сервером для защиты квоты.

## Что проверено разработчиком

13 автоматических проверок данных/серверного протокола и 5 браузерных сценариев: программа, веса, история, резервные копии, вход, согласие, чат, ошибки квоты, выход, отсутствие вкладки библиотеки. Ответы API в тестах заменены фикстурами. Реальный Groq и публикация Netlify Functions требуют действий выше и ещё не проверены. Это web-версия для Safari; нативная iOS-сборка не подготовлена.
