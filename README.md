# LIME FIT 0.3 — браузерная версия

[Скачать LIME-FIT-web.zip](https://github.com/kelimagaksih6-beep/expo/raw/refs/heads/lime-fit-web-preview-20261015/LIME-FIT-web.zip)

Добавлены до 14 дней программы: отдельные названия и упражнения, перестановка, удаление с подтверждением, ручной выбор следующего дня и автоматическое чередование. Существующий план становится первым днём. Начатые и завершённые занятия сохраняют собственные снимки.

Также работают календарь, графики, рекорды и JSON-копии. Новая версия импортирует старые копии; копии формата 2 восстанавливайте в версии 0.3 или новее. Импорт полностью заменяет данные после подтверждения.

1. Перед обновлением экспортируйте JSON через профиль → Резервные копии и данные.
2. Скачайте и распакуйте архив.
3. Для обновления откройте существующий сайт Netlify → Deploys и загрузите папку с index.html, _redirects и _expo. Сохраните прежний адрес и не очищайте данные браузера.
4. Для первого размещения войдите в Netlify и используйте https://app.netlify.com/drop.
5. Откройте адрес сайта на компьютере или телефоне. Для web-версии Expo Go не нужен.

Данные хранятся локально в браузере, без синхронизации. ИИ не подключён. Пользовательские упражнения, диапазоны повторений и архив всех редакций программы пока не реализованы. Нативный запуск не проверен.

Проверены TypeScript, 21 доменный тест и 7 браузерных сценариев. Эта ветка содержит готовый архив и инструкцию, без исходников Expo SDK.
