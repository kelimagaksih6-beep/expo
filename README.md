## Обновление и применение

1. Экспортируйте JSON-копию в профиле текущего приложения.
2. Распакуйте LIME-FIT-web.zip и загрузите папку с index.html, _redirects и _expo в существующий сайт Netlify → Deploys. Сохраните прежний адрес и данные браузера.
3. Откройте Программа → Посмотреть программу на массу → Применить программу. Применение заменит только план, сохранив историю, профиль и начатую тренировку.
4. Для редактирования используйте Редактировать программу. Можно изменить каждую цель подхода отдельно. Для первого занятия выберите нужный день и нажмите Сделать следующим занятием.
5. На телефоне откройте HTTPS-адрес своего сайта в браузере. Expo Go не нужен; записи разных устройств не синхронизируются.

Воскресные веса подставляются как план, не как подтверждённые результаты. Старый RIR не перенесён в цели. В болгарском приседе — 10 кг на каждую гантель (20 кг суммарно); икры — стоя в Смите. Сгибание ног сидя и веса остальных дней нужно заполнить самостоятельно. Для спины по умолчанию выбран верхний блок; на скамье Скотта — EZ-гриф.

В среду 22 рабочих подхода с прессом, в пятницу 20, в воскресенье 29. Воскресенье с разминкой и отдыхом может занять больше 85 минут. Учитывайте восстановление перед понедельничным волейболом.

## Проверки и ограничения

Исходники прежнего Expo-проекта не восстановились в новой среде. Обновление выполнено на восстановленной web-сборке 0.4; материалы для воспроизведения сохранены отдельным архивом. Это не исходный TypeScript-проект и не нативная сборка. Две чистые сборки дали одинаковую контрольную сумму. Выполнены 6 тестов правил данных и 3 браузерных сценария; нативный запуск и TypeScript не проверялись. ИИ не подключён.

Копии формата 4 содержат цели по подходам; старые форматы 1–3 принимаются, но новую копию нельзя импортировать в старую версию приложения. Применение плана поддерживает отмену до изменения нового плана. Не очищайте данные сайта.
