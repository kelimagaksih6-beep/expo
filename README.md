# LIME FIT — браузерная версия

[Скачать LIME-FIT-web.zip](https://github.com/kelimagaksih6-beep/expo/raw/refs/heads/lime-fit-web-preview-20261015/LIME-FIT-web.zip)

Архив содержит готовую web-сборку приложения.

1. Скачайте и распакуйте архив.
2. Зарегистрируйтесь на https://app.netlify.com/signup и откройте https://app.netlify.com/drop.
3. Загрузите папку с index.html, _redirects и _expo.
4. Netlify выдаст ссылку, которую можно открыть в браузере.

Эта ветка содержит только архив и инструкцию, не исходники Expo SDK.

Данные тренировок хранятся локально в браузере. ИИ не подключён. Экспорт/импорт резервных копий и подробные графики ещё не реализованы.
