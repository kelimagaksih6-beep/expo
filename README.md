# LIME FIT 0.2 — браузерная версия

[Скачать LIME-FIT-web.zip](https://github.com/kelimagaksih6-beep/expo/raw/refs/heads/lime-fit-web-preview-20261015/LIME-FIT-web.zip)

Добавлены календарь, графики веса и повторений, рекорды, экспорт/восстановление JSON и удаление данных с подтверждением. Импорт полностью заменяет текущие данные после проверки и подтверждения; повторный импорт не создаёт дубли.

1. Скачайте и распакуйте архив.
2. Для обновления откройте существующий сайт в Netlify → Deploys и загрузите папку с index.html, _redirects и _expo. Сохраните прежний адрес сайта и не очищайте данные браузера.
3. Для первого размещения войдите в Netlify и используйте https://app.netlify.com/drop.
4. Откройте адрес сайта на компьютере или телефоне. Для web-версии Expo Go не нужен.

Данные хранятся локально в браузере, без синхронизации. Резервные копии находятся в профиле. ИИ не подключён. Поддерживается одна программа; несколько дней и пользовательские упражнения пока не реализованы. Нативный запуск не проверен.

Проверены TypeScript, 15 доменных тестов, 5 браузерных сценариев и экспорт web/iOS/Android. Эта ветка содержит готовый архив и инструкцию, без исходников Expo SDK.
