# LIME FIT 0.4 — программа на массу

[Скачать LIME-FIT-web.zip](https://github.com/kelimagaksih6-beep/expo/raw/refs/heads/lime-fit-web-preview-20261015/LIME-FIT-web.zip)

Добавлены подготовленная программа из трёх занятий, восемь упражнений библиотеки, диапазоны повторений, отдых и заметки по упражнению. Рабочие веса оставлены пустыми для подбора на тренировке.

## Как открыть программу

1. В текущем приложении экспортируйте JSON через профиль → Резервные копии и данные.
2. Скачайте и распакуйте архив. Обновите существующий сайт Netlify через Deploys, загрузив папку с index.html, _redirects и _expo. Сохраните прежний адрес сайта.
3. Откройте приложение → Программа → Посмотреть программу на массу.
4. Прочитайте план и нажмите Применить программу. Это заменит текущий план, сохранив профиль, историю и начатую тренировку. Можно отклонить предложение; применение можно отменить до последующих изменений плана или единиц веса.
5. Нажмите Редактировать добавленную программу для своих правок. Для другого первого занятия выберите его на вкладке Программа и нажмите Сделать следующим занятием.

Откройте адрес сайта в браузере телефона; Expo Go не нужен. Данные остаются в браузере конкретного устройства. Синхронизации нет. Для первого размещения доступен https://app.netlify.com/drop.

Проверены TypeScript, 25 доменных тестов и 8 браузерных сценариев. Нативный запуск на телефоне не проверен. Онлайн-ИИ не подключён. В сборке нет персональных антропометрических или медицинских данных.

Новые JSON-копии имеют формат 3 и требуют приложения версии 0.4 или новее; старые форматы 1 и 2 можно импортировать. Импорт копии полностью заменяет данные, а применение предложения меняет только программу.

## Нагрузка и восстановление

- Понедельник и четверг — игровая нагрузка; вторник и суббота — восстановление. Верх тела в среду и воскресенье, ноги в пятницу. Названия дней — ориентир: приложение переключает занятия по порядку, без календарных напоминаний.
- Первые 2 недели — подбор нагрузки. В первую неделю в упражнениях с 3 рабочими подходами можно выполнить 2. Не добавляй подходы только ради заполнения 90 минут. Волейбол учитывается как нагрузка для восстановления, но не заменяет силовую тренировку ног.
- Разминка: 5–8 минут лёгкой активности и комфортные движения суставов. Перед первым тяжёлым упражнением — 2–4 постепенно утяжеляющихся разминочных подхода, перед остальными — по необходимости. Разминка не входит в рабочие подходы.
- Подбери вес на нижнюю границу повторений с запасом 2–3 качественных повторения; для жима ногами держи запас 3. Если не получается нижняя граница или меняется техника — уменьши вес. Не проверяй максимумы и не работай до отказа.
- Когда во всех рабочих подходах достигнута верхняя граница с запасом минимум 2 повторения на двух последовательных выполнениях упражнения, добавь минимальный доступный вес (обычно 2–5%) и вернись к нижней границе. Если шаг тренажёра слишком большой, сохрани вес. Приложение не повышает его автоматически.
- При выраженной усталости после игры снизь объём ног на 1 подход в каждом основном упражнении либо перенеси занятие. Если прыжок и восстановление ухудшаются, не повышай нагрузку. Через 2 недели оцени результаты и самочувствие перед добавлением объёма.
- Любое упражнение выполняй только без боли. Тренажёр не гарантирует отсутствие нагрузки на поясницу. При боли прекрати подход; повторяющуюся боль обсуди со спортивным врачом или физиотерапевтом.
